# GitHub Workshop

A beginner-friendly introduction to Git and GitHub using **GitHub Desktop**, made for the [Reality Bending Lab](https://realitybendinglab.com/) at the University of Sussex.

👉 **[View the slides](https://anafneves.github.io/Github_Workshop/workshop.html)**

## What it covers

- Why use Git and GitHub
- Key ideas: repository, fork, clone, commit, push, pull, pull request
- Setting up GitHub Desktop
- The workflow: fork ➜ clone ➜ commit ➜ push ➜ pull request
- Hands-on exercise: add a memory to the REBEL website

No prior experience needed.
